دليل تشغيل التطبيق بسيرفر وقاعدة بيانات مجاناً 🚀

لماذا لا يعمل الدخول وحفظ البيانات على GitHub Pages؟

خدمة GitHub Pages مخصصة لصفحات الويب الثابتة فقط (Static HTML). بينما هذا التطبيق يحتوي على خادم حقيقي (Node.js/Express) لحفظ البيانات ومزامنتها لحظياً بين كل الهواتف وأجهزة الكمبيوتر بدون فقدان.

3 خطوات بسيطة لتشغيله مجاناً على Render.com (دقيقة واحدة):

  1. ادخل على موقع render.com واضغط Get Started for Free وسجل دخولك بحساب GitHub.
  2. اضغط على زر + New ثم اختر Web Service واختر مستودع هذا المشروع (Repository).
  3. اضبط الإعدادات كالتالي:
    • Runtime: Node
    • Build Command: npm install && npm run build
    • Start Command: npm start
  4. اضغط Deploy Web Service، وسيعطيك رابطاً خاصاً بك (مثال: your-studio.onrender.com) يعمل بكامل الصلاحيات والسيرفر وقاعدة البيانات من أي موبايل أو كمبيوتر!
